# Wadjet-Link Rust Bindings

This workspace contains Rust bindings for the Wadjet-Link automotive Ethernet validation framework.

## Crates

| Crate | Description |
|-------|-------------|
| `wadjet-sys` | Low-level FFI bindings generated by bindgen |
| `wadjet` | Safe, idiomatic Rust wrapper around wadjet-sys |

## Prerequisites

- Rust 1.70+ (for stable async)
- Clang (for bindgen)
- Wadjet-Link C library (`libwadjet_c.so`)

## Building

```bash
# Build the C library first
cd ../..
cmake -B build -DWADJET_BUILD_C_BINDINGS=ON
cmake --build build

# Build Rust crates
cd bindings/rust
cargo build
```

## Usage

Add to your `Cargo.toml`:

```toml
[dependencies]
wadjet = { path = "path/to/wadjet-link/bindings/rust/wadjet" }
```

## Example

```rust
use wadjet::{CaptureSession, CaptureOptions};

fn main() -> wadjet::Result<()> {
    // Create capture session
    let mut session = CaptureSession::new("eth0", CaptureOptions::default())?;
    
    // Set filter
    session.set_filter("udp port 30490")?;
    
    // Start capturing
    session.start()?;
    
    // Read packets
    while let Some(packet) = session.next_packet(1000)? {
        println!("Packet: {} bytes", packet.len());
        
        // Decode protocol stack
        if let Ok(result) = packet.decode() {
            if result.has_someip() {
                let someip = result.someip().unwrap();
                println!("  SOME/IP Service: {:#06x}", someip.service_id);
            }
        }
    }
    
    Ok(())
}
```
